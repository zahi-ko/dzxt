# ADR 0006: 拓展功能范围确定为三项

**日期**：2026-09-06
**状态**：已接受
**相关**：AGENT.md 第 1 节、PLAN.md 阶段三、ADR 0004

## 背景

题目表要求拓展功能至少实现一项且结果正确可靠。此前仅确定语音克隆（见 ADR 0004）。现拓展功能范围最终确定，在语音克隆之外新增两项。

## 决策

拓展功能共三项，均必做：

1. **语音克隆**（既有，本地 GPT-SoVITS，见 ADR 0004）
2. **录音质量检测**：对录音自动评估三项指标——
   - 音量过轻（RMS / 峰值电平与阈值比较）
   - 疑似爆音（样本触顶削波比例统计）
   - 环境噪声嘈杂程度（无声段底噪估计）
   三项指标综合判断，给出「是否需要重录」的直观建议。
3. **语音加噪与降噪**：可调信噪比（SNR）的加噪 + 谱减法降噪，形成加噪 → 降噪闭环验证（处理前后信噪比可量化对比）。

## 理由

- 录音质量检测与系统采集环节天然衔接：录音完成即出报告，演示链路完整，实现成本可控（纯 DSP 统计，无需新依赖）。
- 加噪为降噪提供可控的验证手段：自加噪 → 降噪 → 信噪比对比，结果「正确可靠」可量化，契合结题验收标准。
- 两项均为纯算法实现，走现有效果器注册表 / analysis 模块，不动契约层架构。

## 后果

- PLAN.md 阶段三拆分为 3.1–3.5（克隆 / 质量检测 / 加噪降噪 / 集成 / 交付物）。
- 加噪与降噪进入效果器注册表，按铁律三「一个效果一个文件」接入。
- 明确不做范围不变：语音识别、语音合成、端点检测、语音助手、深度伪造检测。
