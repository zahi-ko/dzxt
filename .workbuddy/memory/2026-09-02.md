### 锁定的技术决策（详见 docs/adr/）

- ADR 0001：音频采集与播放**后端独占**（sounddevice），前端只做展示
- ADR 0002：后端 FastAPI + Pydantic v2 + uvicorn，不用 Gradio/Streamlit
- ADR 0003：前端 **Vue 3 + Vite**（JS 非 TS），Vite proxy 转发 /api
- ADR 0004：语音克隆**纯本地 GPT-SoVITS**，独立进程 + 独立环境，不用云端 API

### 关键约定（写进了 AGENT.md）

- 三条铁律：内部音频统一 float32 + sr；audio_id 句柄制；效果器注册表（纯函数 + @register）
- 模块归属是**软约束**（可跨目录改，改了记变更日志并知会 owner），唯一硬约束是 schemas.py 契约层改动需全组同步
- 拓展功能范围：只做语音克隆，明确不做 ASR/TTS/VAD/语音助手/伪造检测
